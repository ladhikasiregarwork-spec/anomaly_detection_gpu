# Python packages for text_based_anomaly_detection.ipynb
#   pip install -r requirements.txt
# Everything here is pure pip — there is NO separate system software to install.
# (PDF reading uses pypdfium2, OCR uses rapidocr-onnxruntime — both bundle their
# engines inside the wheel: no Poppler, no Tesseract.)
# NOTE (this hardware — Intel 8th-gen CPU, no AVX-512): torch>=2.3 and onnxruntime>=1.19 fail to
# even IMPORT here ("DLL initialization routine failed") — their newer builds need AVX-512.
# Pinned to versions that load on AVX2-only CPUs. The cu121 CUDA build ALSO fails the same way
# once a GPU driver is active (cublas64_12.dll) — use cu118 instead, verified working here.
# Run this BEFORE `pip install -r requirements.txt` (otherwise torch installs CPU-only):
#   pip install torch==2.2.2 --index-url https://download.pytorch.org/whl/cu118
torch==2.2.2
# transformers>=5 raises its minimum torch requirement to >=2.4 and silently disables the PyTorch
# backend if it sees 2.2.2. Stay on the 4.x line (what this repo was built/tested against).
transformers>=4.40,<5
rapidocr-onnxruntime>=1.3
onnxruntime==1.17.3
pypdfium2>=4
pillow>=10
# torch==2.2.2 is compiled against numpy 1.x; numpy>=2 makes tensor<->numpy conversion CRASH
# (not just a warning). opencv-python>=5 requires numpy>=2, so it's pinned <5 too.
numpy<2
opencv-python<5
matplotlib>=3.8
# For running the notebook itself:
jupyter>=1.0
ipykernel>=6.29
